# Поле

**Демонстрация интерфейса для анализа футбольного видео.**

[Открыть демонстрацию](https://wolfiejustfine.github.io/pole-football-demo/)

«Поле» — исследовательский прототип, который объединяет видео матча, схему поля и инструменты разбора игровых эпизодов. Эта публичная версия содержит короткую запись анализа из локального прототипа и интерактивную схему на условных данных. Сам сайт не загружает и не анализирует видео.

## Что представлено

- Рабочий процесс от видеозаписи к позициям и разбору эпизодов.
- Записанный фрагмент анализа: видео, рамки обнаружения и карта поля.
- Интерактивное превью с тремя демонстрационными ситуациями.
- Адаптивная страница для компьютеров и мобильных устройств.

Локальный прототип отдельно поддерживает обработку футбольных трансляций, визуализацию позиций, ручную разметку и экспорт результатов. Он находится в разработке; распознавание и статистика требуют проверки аналитиком.

## Запуск демонстрации

Откройте `index.html` в браузере или перейдите на страницу GitHub Pages репозитория. Установка и доступ в интернет не требуются.

## Статус

Это демонстрационный проект, а не готовый коммерческий продукт. Интерактивные события условные. Запись показывает реальный результат прототипа; позиции могут быть неточными и требуют проверки по видео.
